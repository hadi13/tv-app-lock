# كيف يشتغل التطبيق من الداخل

## الفكرة العامة

التطبيق ما يحتاج صلاحيات root ولا مالك جهاز (Device Owner). كل شي مبني على **خدمة إمكانية الوصول** (`AccessibilityService`)، لأنها الطريقة الرسمية الوحيدة اللي تخلي تطبيق عادي:

1. يعرف أي تطبيق ظاهر على الشاشة الحين.
2. يفتح شاشة فوق أي تطبيق بدون قيود التشغيل في الخلفية.
3. يصوّر الشاشة (`takeScreenshot`، من Android 11) بدون رسالة موافقة كل مرة.
4. يعرض نافذة تنبيه فوق كل شي (`TYPE_ACCESSIBILITY_OVERLAY`) بدون صلاحية «العرض فوق التطبيقات».
5. يقرا النصوص الظاهرة (اسم القناة في Live TV).

```
┌──────────────┐   حدث: نافذة جديدة    ┌───────────────┐
│ أي تطبيق     │ ─────────────────────▶ │ LockService   │
└──────────────┘                        │  • Rules      │──▶ LockActivity (شاشة الرقم)
                                        │  • Usage      │──▶ نافذة العد التنازلي
                ┌───────────────┐       │  • Events     │──▶ ntfy.sh (اختياري)
  الجوال ──HTTP▶│ WebServer:8787│◀─────▶│  • screenshot │
                └───────────────┘       └───────────────┘
```

## مسار القفل

1. `LockService.onAccessibilityEvent` يستقبل `TYPE_WINDOW_STATE_CHANGED` مع اسم الحزمة.
2. يتجاهل: لوحة المفاتيح، `systemui`، وتطبيقنا نفسه.
3. `Rules.blocked(pkg)`:
   - إذا الحزمة ما تنقفل (الواجهة الرئيسية، تطبيقنا) ← لا.
   - إذا فيه فتح بالرقم السري ساري (`Store.isUnlocked`) ← لا. **الفتح بالرقم يتجاوز كل القواعد.**
   - إذا مقفل بالرقم، أو وقت النوم، أو خلص الحد اليومي ← نعم.
4. إذا مقفل: يفتح `LockActivity` (`singleInstance`، خارج قائمة التطبيقات الأخيرة).
5. بعد الرقم الصحيح والمدة، `Store.unlock(pkg, until)` ويرجع للتطبيق.

### أنواع الفتح (`until`)

| القيمة | المعنى |
|---|---|
| `0` | مقفل |
| وقت بالمللي ثانية | مفتوح لين هالوقت |
| `-1` (`FOREVER`) | مفتوح لين يتقفل يدوياً |
| `-2` (`ONCE`) | مفتوح لين يتغير التطبيق الظاهر (`relockOnceExcept`)، ويتصفّر بعد إعادة التشغيل |

## الدورة كل ١٠ ثواني (`tick`)

- `flushUsage()`: يضيف الوقت للتطبيق الظاهر (بس والشاشة شغالة، ومع حد أقصى دقيقتين للدفعة الوحدة عشان النوم ما ينحسب).
- **بداية وقت النوم:** `relockAll()` مرة وحدة (علامة `bed_applied`) + تنبيه.
- `check()`: إذا انتهت مدة الفتح أو خلص الحد اليومي ← شاشة القفل.
- `countdown()`: `Rules.timeLeft` = الأقرب من (نهاية الفتح، باقي الحد اليومي، بداية وقت النوم). عند ٥ دقايق ودقيقة يطلع شريط أصفر ١٥ ثانية.
- تسجيل القناة إذا ظلت نفسها دقيقة.

## الواجهة الرئيسية (`HomeActivity`)

نشاط فيه `MAIN` + `HOME` + `DEFAULT`. سكربت `windows/6-set-home.bat` يخليه الأساسي عن طريق `cmd package set-home-activity`، ويعطّل الواجهات الأصلية ومعالج إعداد Google TV (`com.google.android.tungsten.setupwraith`) لأنه ياخذ زر الرئيسية بأولوية أعلى من أي واجهة خارجية. و`7-restore-google-home.bat` يرجّعها.

- اللغة والاتجاه من `Locale.getDefault()`: عربي ومن اليمين، أو إنجليزي ومن اليسار.
- «الأكثر استخداماً» = أعلى ٣ تطبيقات بوقت المشاهدة خلال ٧ أيام (دقيقة على الأقل)، والباقي في شبكة من ٥ أعمدة. التطبيقات اللي في `Store.hidden` ما تظهر.
- البطاقات تستخدم صورة التطبيق للتلفزيون (`getApplicationBanner` / `getActivityBanner`) بـ `CENTER_CROP`، وإذا ما فيه، تطلع الأيقونة على لون داكن محسوب من ألوانها.
- التحديد: تكبير وظل واسم يظهر تحت البطاقة. القص مطفي في الحاويات (`clipChildren`/`clipToPadding`) عشان البطاقة المرتفعة ما تنقص.
- لما تكون واجهتنا ظاهرة، `LockService` يخلي `current` = حزمتنا (من اسم الكلاس في الحدث) عشان ما ترجع شاشة القفل لتطبيق قديم، ويقفل اللي كان مفتوح «هذي المرة بس».

## سجل الاستخدام

`SharedPreferences` باسم `tvlock_usage` بمفاتيح `yyyyMMdd|package` ← مللي ثانية. يُحذف ما هو أقدم من ١٤ يوم. شاشة مطفية (`ACTION_SCREEN_OFF`) توقف العد.

## تصوير الشاشة

`takeScreenshot` يرجّع `HardwareBuffer`. نحوّله لصورة عادية بثلاث طرق ونختار أول وحدة مو سودا (بعض الشاشات ترجّع أسود مع طريقة معيّنة)، ونتذكر الطريقة الناجحة:

1. `Bitmap.wrapHardwareBuffer(colorSpace).copy(ARGB_8888)`
2. نفسها مع `sRGB` صريح
3. رسم بالـ GPU داخل `ImageReader` وقراءة البكسلات

الصورة تتصغّر لعرض 960 وتنضغط JPEG بجودة 65، وأقل فاصل بين لقطتين 700ms (حد النظام 333ms).

**ليش Live TV أسود؟** فيديو الموالف (Tuner) يُعرض بطبقة عتاد مستقلة (sideband/overlay) ما تمر على SurfaceFlinger، فأي تصوير برمجي (حتى `adb screencap`) ما يشوفها.

## اسم القناة

مع `canRetrieveWindowContent` و`flagRetrieveInteractiveWindows`، عند أي `TYPE_WINDOW_CONTENT_CHANGED` من حزمة قنوات (`livetv`، `tvinput`، `tuner`...) نمر على كل النوافذ ونجمع النصوص الظاهرة (حد ٣٠٠ عنصر). الاختيار:

1. معرّف العنصر (view id) فيه `channel` + `num/no` ← رقم القناة.
2. معرّف فيه `channel` ونص مو رقم ← اسم القناة.
3. معرّف فيه `program/event/epg` ← البرنامج.
4. بديل: أول رقم قصير، وأول نص مو وقت.

النصوص الخام متاحة في `/debug/info` (`live dump`) عشان نضبط القراءة لأي شاشة.

## الإعدادات المحفوظة (`Store`)

| المفتاح | الوصف |
|---|---|
| `pin_hash` | SHA-256 للرقم السري مع ملح ثابت |
| `locked` | مجموعة الحزم المقفلة بالرقم |
| `until_<pkg>` | حالة الفتح |
| `limit_<pkg>` | الحد اليومي بالدقايق |
| `bed_on/bed_start/bed_end` | وقت النوم (دقايق من منتصف الليل) |
| `web_on` / `web_token` | لوحة الجوال ورمز الجلسة (يتجدد مع تغيير الرقم) |
| `ntfy_on` / `ntfy_topic` | إشعارات ntfy |
| `hidden` | التطبيقات المخفية من الواجهة |

## ليش `targetSdkVersion 29`؟

يتجنب قيود الأنظمة الأحدث على تشغيل الأنشطة والخدمات، وما يحتاج `QUERY_ALL_PACKAGES` لقراءة قائمة التطبيقات. التطبيق يُبنى ضد API 34 عشان يستخدم `takeScreenshot` وغيرها، مع فحص `Build.VERSION.SDK_INT` قبل أي واجهة جديدة.
